# **買い物メモアプリ**
## 1.目的
買い物メモアプリを通して、HTML,CSS,C#の基礎を勉強する。
## 2.使用技術
- **バックエンド：** C# (ASP.NET Core Razzor Pages)
- **フロントエンド：** HTML,CSS
- **バージョン管理：** Git,GitHub
## 3.現在の機能 (実装済み)
- [x] アイテムの一覧表示
- [x] 新規アイテムの追加(別ページへのルーティング)
- [x] 完了状態のチェックボックス切り替え
- [x] アイテムの削除機能
- [x] データベース(Postgres)との連携によるデータ永続化
